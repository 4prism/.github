# 주식회사 포프리즘 · 치과 데스크알리미

**치과 데스크알리미**는 덴트웹을 쓰는 치과의 데스크 업무를 자동화하는 Windows 프로그램입니다.
치과 원장이 자기 치과 데스크에서 쓰려고 만들었습니다.

- 보험 청구 서류(실비·치아보험) 5종 한 번에
- 리콜 전화 — 오늘 전화할 분과 첫마디, 통화 결과는 덴트웹 차트에 저절로 기록
- 부재중 전화 · 지각 환자 · 수술 전·후 콜 · 예약 빈자리 알림
